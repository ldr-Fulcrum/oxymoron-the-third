# Redactions

Every screenshot in this folder is a **redacted copy for privacy** of an original full-frame (1920x1080) PNG extracted from screen recordings of the IBM Bob IDE. Originals are retained privately and are not included in this repository. Redaction is solid black rectangles only; no Bob chat content, task summary, diff, or tool entry was altered, cropped, or regenerated.

## What was redacted

- **All screenshots:** two regions of the IDE status bar: a notification about an unrelated third-party repository pull request, and the name of an unrelated local project.
- **Five split-view frames from recording-20260926-165911** (shell-failure, test-evidence-limitation, retrospective-preflight-disclosure, acceptance-boundary-and-repair-entry, repair-tests-added): the editor and file-explorer panes to the right of the Bob panel. These panes showed an internal project-coordination file and internal file names, not Bob activity. The Bob panel on the left is unaltered.
- **fulcrumforce_ldr_shell-failure_02m00s:** additionally, a local filesystem path in the text of one Bob tool entry (the workspace directory prefix before `oxymoron-the-third`).
